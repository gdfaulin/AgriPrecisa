about=AgriPrecisa gathers precision agriculture tools for QGIS, developed at Fatec Pompeia "Shunji Nishimura" (Brazil). This first release provides "IDW vector grid": soil or plant sample points are interpolated by IDW (power, search radius and pixel size set by the user) over the bounding box of the field boundary, accepting samples slightly outside the boundary through a tolerance. A vector grid (cell size chosen by the user, or an existing grid) receives, by zonal statistics on whole cells, the mean of every interpolated field and is then clipped by the boundary, ready for management zones and variable rate maps. Results are styled as graduated maps (5 classes, Jenks natural breaks, RdYlGn). Available as a step-by-step wizard (Vector > AgriPrecisa) and as a Processing algorithm for batch runs and the Graphical Modeler. Interface in Portuguese, English and Spanish. Unlike general interpolation tools, it delivers the result directly as a pixel-sized vector grid clipped to the field, with one styled layer per attribute.

    1.6.0 Minimum (4) and maximum (default 16) of neighbours per pixel, as in GIS interpolators: the minimum is always met, even beyond the radius; the maximum limits the radius. Auto-fit now chooses P and the maximum of neighbours by cross-validation and sets the radius so it does not cut the maximum. Step 3: weight curve removed, map preview fills the right column, search radius moved to a collapsed Advanced box. Processing: new minimum and maximum of neighbours parameters.
    1.5.2 Fix: pixels the search radius did not reach (e.g. a wider gap between sensor passes) were left empty and grid cells came out blank; they now use the 4 nearest samples. Warning in step 3 and in the final message with the % of the field affected.
    1.5.1 Help updated for the vector grid and the pixel size; Processing help shows the standard grid file name correctly.
    1.5.0 Vector grid: cell size chosen by the user (independent of the pixel) or an existing grid; standard grid saved as "<boundary>_Grade Padrão_<cell>x<cell>.shp" and reusable; outputs in Shapefile with columns named after the attributes; rasters cover the boundary plus 100 m and are never clipped; zonal mean computed on whole cells and the grid clipped only afterwards (no border cells without value).
    1.4.0 Step 3: single teaching layout (standard layout removed) with wider sliders (P 0.5 to 5.0, radius 1x to 6x); weight chart corrected after Shepard (1968): 1/d^P relative to the typical pixel-to-sample distance, cut axis, distance ticks; new bars with the share of each neighbour in a typical pixel; cross-validation covers P 0.5 to 5.0.
    1.3.2 Step 1: output folder defaults to the last folder used or, the first time, to an AgriPrecisa subfolder inside the project folder (created automatically).
    1.3.1 Renamed: "Auto-fit" / "Auto-fit all" buttons; "Teaching layout" (student, visual) and "Standard layout" (free values); origin "auto-fit" in the parameter table.
    1.3.0 IDW parameters per attribute: each attribute keeps its own P and radius (attribute selector, summary table with origin, "Suggest for this one" and "Suggest for all"); suggested radii never leave gaps in the map; Processing option to choose P and radius of each attribute by cross-validation.

    1.1.0 Student mode in wizard step 3: sliders for power P (1 to 3) and search radius (multiples of the mean sample spacing) with explanations, weight x distance curve and live map preview; advanced mode keeps free numeric fields; chosen mode is remembered.
    1.0.3 Wizard step 2: sample counts and density shown left-aligned and only on layer rows.
