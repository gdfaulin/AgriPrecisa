# AgriPrecisa

Precision agriculture tools for QGIS. Ferramentas de agricultura de precisão para o QGIS.

Tools: **IDW vector grid** (Vector > AgriPrecisa, and Processing Toolbox > AgriPrecisa) and **DTM and plant height in row crops** (Raster > AgriPrecisa, and Processing Toolbox > AgriPrecisa > Elevation models).

Documentation: https://github.com/gdfaulin/AgriPrecisa
